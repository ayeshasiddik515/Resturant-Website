# Aizome (藍染) | Japanese Kitchen website

Ekhon ekta page ache: Home (`index.html`).

## Kibhabe kholen
`index.html` e double click korun, browser e khule jabe.

## Folder
```
aizome-restaurant/
  index.html      Home page (HTML + CSS + JavaScript, ekta file)
  photos/         Food er chobi ekhane rakhun
  README.md       Ei file
```

## Edit kora
`index.html` er niche `<script>` er moddhe:

- `MENU`     dish, price, photo, featured (hero slideshow te dekhabe kina)
- `REVIEWS`  guest review ar rating (average nijei hishab hoy)

Photo dite: chobi `photos/` folder e rakhun, tarpor `image: ''` er jaygay `image: 'photos/ramen.jpg'` likhun.

`[ ]` bracket er lekha gulo (address, phone, hours, tagline, story) apnar tothyo diye bodle nin.

## Live kora
- Netlify Drop: app.netlify.com/drop e folder ta drag kore din
- GitHub Pages: repo te upload kore Pages on korun

## Note
Dish, price ar review ekhon sample. Real tothyo na dile publish korben na.
